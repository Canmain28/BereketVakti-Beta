# Bereket Vakti Beta

Bereket Vakti'nin Android Beta sürümünü [GitHub Releases](../../releases) sayfasından indirebilirsiniz.

Android 7.0 ve üzeri gerekir. Mevcut Bereket Vakti kurulumunda **Güncelle** seçeneğini kullanın. Zikir kayıtlarını korumak için uygulamayı kaldırmadan ve verilerini temizlemeden ilerleyin.
